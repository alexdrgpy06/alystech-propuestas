# Interactive Proposal Builder — one-time purchase

Turn each service proposal into a clear, editable presentation that is ready to share. Interactive Proposal Builder lets buyers compare packages, add eligible extras, keep initial investment separate from annual charges, and download an A4 proposal PDF.

## Included

- Self-contained web application that runs locally.
- Spanish and English interface, with `/es/` and `/en/` routes.
- Three fully synthetic examples: website, managed services, and consulting.
- Commercial editor for brand, client, currency, prices, terms, options, and extras.
- JSON configuration import and export.
- Local decision receipts and A4 PDF export.
- Source code, tests, dependency lockfile, licenses, and an AI-assisted modification guide.

## How it works

The seller selects an example or configures a proposal, edits it in the browser, and saves its configuration locally. The client compares alternatives and downloads the PDF. Data stays in that browser; the product requires no accounts, database, CRM, payments, email, webhooks, or cloud synchronization.

## Requirements

Node.js 20.19 or later. The first dependency install needs access to the npm registry or a corporate cache; after dependencies are installed, it can run offline. There are no usage fees, AI API calls, or mandatory services.
