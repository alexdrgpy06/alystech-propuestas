# Interactive Proposal Builder — compra única

Convierte cada propuesta de servicios en una experiencia clara, editable y lista para presentar. Interactive Proposal Builder permite comparar paquetes, sumar complementos compatibles, separar la inversión inicial de los cargos anuales y descargar una propuesta en PDF A4.

## Incluye

- Aplicación web autocontenida para ejecutar localmente.
- Interfaz en español e inglés, con rutas `/es/` y `/en/`.
- Tres ejemplos completamente sintéticos: sitio web, servicios gestionados y consultoría.
- Editor comercial para marca, cliente, moneda, precios, términos, opciones y complementos.
- Importación y exportación de configuraciones JSON.
- Recibos locales de decisión y exportación de PDF A4.
- Código fuente, pruebas, bloqueo de dependencias, licencias y guía de modificación con IA.

## Cómo funciona

El vendedor elige un ejemplo o configura una propuesta, ajusta el contenido desde el navegador y guarda la configuración localmente. El cliente compara las alternativas y descarga el PDF. Los datos se conservan en ese navegador; el producto no requiere cuentas, base de datos, CRM, pagos, correo, webhooks ni sincronización en la nube.

## Requisitos

Node.js 20.19 o posterior. La primera instalación de dependencias requiere acceso al registro de npm o una caché corporativa; después se puede ejecutar sin conexión con las dependencias instaladas. No hay cuotas, llamadas a APIs de IA ni servicios obligatorios.
